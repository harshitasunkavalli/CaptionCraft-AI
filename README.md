# CaptionCraft AI ✨

A simple social media caption generator built with Python and Streamlit.

## Features
- Business type selection
- Product or post topic input
- Language selection
- Caption tone selection
- Caption download interface

## Tech Stack
- Python
- Streamlit
- Requests

## Run Locally
pip install -r requirements.txt
streamlit run app.py

Note: AI generation is not enabled in this version yet.
